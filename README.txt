HOW TO PUBLISH:
1. Create a new PUBLIC GitHub repository, e.g. sp-pickles-shop.
2. Upload every file in this folder to the repository root (index.html, sp-logo.jpg, mango.jpg, lemon.jpg, chilli.jpg, gongura.jpg, bittergourd.jpg, tomato.jpg, coriander.jpg).
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Wait for GitHub Pages to publish, then open https://YOUR-USERNAME.github.io/sp-pickles-shop/
5. Test all seven products, Telugu/English toggle, cart and WhatsApp checkout on a phone.
6. GitHub Pages is static hosting; review its current terms for commercial use before launch. The site does not store orders in a database or process online payments. WhatsApp is the order handoff.
